# Визуализатор динамики туристского потока

## Описание

Тестовое задание.
Визуализатор отражает динамику туристского потока в млн прибытий по категориям туристов.

Стек: React, TypeScript, Vite, Redux Toolkit, Recharts.

Приложение запускается на `http://localhost:3000`.

## Требования

- Node.js `^20.19.0` или `>=22.12.0`
- npm 10+

## Установка и запуск

```bash
npm install
npm run dev
```

Другие скрипты:

```bash
npm run build    # проверка типов и production-сборка
npm run preview  # просмотр собранного приложения
npm run lint     # ESLint
```
